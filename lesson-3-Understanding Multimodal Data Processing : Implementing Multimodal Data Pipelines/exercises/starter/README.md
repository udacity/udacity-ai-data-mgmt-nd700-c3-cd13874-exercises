# README — Multimodal Catalog Pipeline Exercise

## Overview

In this exercise, you will extend a multimodal data pipeline used for building a retrieval-augmented generation (RAG) system over an apparel catalog.

The current pipeline processes a catalog PDF and prepares data for retrieval and question answering. It performs the following steps:

- Extracts text from each PDF page
- Extracts one image per page (currently the largest image)
- Preprocesses the image (resize, normalization, tensor layout metadata)
- Uses a vision model to generate a structured description of the image
- Combines text and image description into a document
- Stores embeddings in a Chroma vector database
- Allows users to ask questions about the catalog using RAG

However, many catalog pages contain multiple images of different products. The current implementation only captures the largest image, which means important information is lost.

**Your task is to modify the pipeline so that it can process every image on a page, not just the largest one.**

## Why This Matters

This change significantly improves retrieval.

### Before

User asks: *"Show me the red running shoes."*

- The system retrieves the page description containing multiple shoes.
- The model must guess which shoe is relevant.

### After

- Each shoe is indexed separately.
- The retriever can return the specific shoe image and description, improving accuracy.

> This is a key principle in RAG system design: **Smaller, semantically meaningful chunks improve retrieval quality.**

Instead of creating one document per page, you should create one document per image.

Your loop should look conceptually like this:


## Design Discussion

This exercise highlights an important architectural choice in multimodal pipelines:

> **Should we index pages, or individual visual elements?**

Indexing individual elements typically provides:

- Better retrieval accuracy
- Smaller semantic units
- More precise answers

However, it increases:

- Number of embeddings
- Storage size
- Indexing time

Understanding these tradeoffs is essential when designing real AI systems.
